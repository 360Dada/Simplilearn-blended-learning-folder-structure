Vendor OneDrive Onboarding
Complete this checklist every time you onboard a new vendor
Access rules — effective immediately
🚫
"Anyone with the link" option has been permanently disabled.
This option is no longer available in OneDrive. It cannot be used at any stage — not during POC, not during production, not for any reason.
✅ Approved sharing options — vendors only
Specific People — use for all active vendor assignments
People with existing access — use when expanding access post-confirmation
Onboarding process — follow in order
1
Create the vendor folder
Create folder inside Vendors / [Vendor Name] following the default naming convention. The programme folders inside must match Internal naming exactly.
2
Collect all vendor email IDs
Before sharing anything, collect the full email list from the vendor. Do not share until you have at least one confirmed email.
3
Share using Specific People — minimum one team member before POC
Share with at least one or more vendor team members using Specific People option only. Set to view or edit as appropriate for the task.
4
Send onboarding email with activation steps
Send the standard activation email to the vendor with the folder link and 5-step activation process: (1) Check inbox/spam for activation email → (2) Click Open → (3) Click Send Code → (4) Copy verification code from second email → (5) Enter code and click Verify.
5
Confirm vendor has completed activation
Do not share production files until the vendor confirms they can access the folder successfully. Get written confirmation.
6
After POC confirmation — expand access if needed
Once POC is confirmed and agreement is in place, add additional vendor team members using Specific People or People with existing access. Never use open link access.
7
Brief the vendor on naming conventions
Share the file naming guidelines with the vendor. All files submitted must follow the AIML_CRS##_L.TT_Title naming convention. Reject any files that do not comply.
